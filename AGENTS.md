# Project conventions

- Update both `README.md` and `README.en.md` in the same change whenever a user-visible feature, setting, interaction, or installation step changes. Document how to use the final behavior and keep current download versions synchronized.
- Keep the README focused on the shipped product. Put implementation details and historical validation in `docs/`. Refresh screenshots or interaction recordings when the documented UI changes; label sample files and simulated previews accurately.
