# 悬浮窗、快捷键与文件关系图

目标版本：**0.1.0-alpha.6**。最终安装包验证与下载入口将在实测完成后补充。

- 收起状态增加圆角层次、明暗与边缘阴影。整块图标可拖动，移动超过 4 px 后交给系统窗口管理器；普通点击与键盘激活仍可展开。
- 展开面板的整个标题栏空白、Logo 与品牌文字均可拖动。标题栏随内容滚动保持可见，设置、收起和菜单按钮不触发拖动。
- GTK 原生窗口拖动会中断 WebKit 的 PointerEvent 序列，改用鼠标事件维持连续拖动和后续点击。
- 快捷键增加重新注册入口与最近触发时间。启动注册失败后，保存相同快捷键也会重试；占用未解除时显示错误并保留原设置。
- 检查 Nautilus 桥接实际是否已加载，首次安装或升级后提示用户保存操作并手动重新打开 Nautilus；不会自动退出文件管理器。无托盘提示不再覆盖桥接提示。
- 文件关系图读取已有打包计划，双向发散展示文件夹与文件；支持展开/收起、分批显示、画布平移、滚轮/按钮缩放和适应画布。选中节点可查看源路径、打包路径与大小，并定位来源。
- 不可读取的来源单独列为待处理节点，不伪装成可打包内容。图中操作不修改收集清单、源文件或打包计划；单屏节点数量有上限，完整内容保留在目录预览中。

验证范围以 Ubuntu 22.04 / GNOME X11 为主要桌面回归环境，同时保留 Ubuntu 24.04 安装兼容性。Wayland 与 Windows/macOS 文件管理器完整交互仍按原验证记录处理。
